## 2. 命令点位（与盒子 `default_point.cpp` 一致）

| 命令 | 点位 | 盒子实现 |
|---|---|---|
| 启动 | `X45` | `startWashCar` 过准入后**只写这一个点**，写一次就留在 PLC 里 |
| 停止 | `M0` | `stopWashCar` 只写 `M0=true`，不动 `X45` |
| 复位·第一步 | `M0` | `resetWashCar` 先写 `M0=false`（clearStop） |
| 复位·第二步 | `M100` | `sleep(1)` 后写 `M100=true`；之后由梯形图进入 S0 时 `CALL P0 → ZRST M1 M131` 清掉 |

看板上的「启动 / 停止 / 复位」三个按钮就是这三条命令；盒子在线时走 MQTT，没有盒子才直接写点。

## 3. 启动前置检查（对应 `startChecks`）

| 检查 | 信号 | 通过条件 | 看板动作 | 动作做什么 |
|---|---|---|---|---|
| 车辆停放到位 `washPosition` | `M187` | =1 | 车辆到位 | 台车回装载位（`pos=0`）、`M515=1`，清 `X24/X3/X75` 的强制 |
| 启动前置条件 `startCondition` | `M1` | =1 | 无（合成） | 梯形图由故障位/防撞杆/车高/限位合成，没有单一外部输入 |
| 左防撞杆 `antiCollisionBarLeft` | `X62` | =1 | 松开左杆 | 写 `X62=1` |
| 右防撞杆 `antiCollisionBarRight` | `X63` | =1 | 松开右杆 | 写 `X63=1` |
| 车辆高度 `vehicleHeightOk` | `X46` | =1 | 车辆达标 | 写 `X46=1` |

### `M187` 为什么不是“复位就 1”

- `M187` 的最终写入在 **S1 步内**（主程序 `#1716–#1756`）：`M187 = M515 & T61`；
- `T61` 是 `M515 & !X3 & X24` 的 **3 秒确认定时器**（K30 × 100ms）；
- 上电停在 S0，这段不执行 → `M187=0`；复位进入 S1 后要**再等 3 秒**才变 1；
- 车没到位（`M515=0` / `X3=1` / `X24=0`）时，复位也不会让 `M187` 变 1，启动照样被拒。

主程序 `#423` 另有一个 `M187 = M515 & !X003 & X024 & S1` 的线圈，会被上面的 `#1756` 覆盖，**不要拿它当最终值**。

## 5. 故障码（D2）

- 30 条说明在 `machine.FAULT_CODES`，与 `src/common/config/default_point.cpp` 的 `faultCodes` 对齐；
- 未收录的码（如梯形图注释里出现过的 25/26/37）看板会显示“未收录”，以盒子实装为准；
- `X50` 液位是**低电平有效**：0=缺水、1=正常（与其它故障位方向相反）；
- 停止类信号：`X44`（按了停止）、`S0`（设备在停止状态）。

## 6. 现场物理模型（`plant.py`）

| 机构 | 状态 | 反馈 | 说明 |
|---|---|---|---|
| 台车 | `pos`（行走脉冲）、`pulse` | `C220` 计数、`X1` 前位、`X75` 后限位、`X3`（pos≥150）、`X24`（pos≤0） | `FRONT_LIMIT=999999`：`X1` 在本模型里不置位——梯形图对它的两处约束（C220 630~850 才允许闭合）与 S4 要走到 1100 才转步**本身不自洽**，现场待确认 |
| 顶刷 | `brush_pos`、`brush_pulse` | `X5` 上位、`X6` 下限位、`X7` 脉冲、`C222` | `TOP_DEPTH=50`，与 `C222` 预设 K50 一致 |
| 侧刷 | 开/合阀动作 | `X10/X11`（左）、`X14/X15`（右） | 开阀后反馈延迟 `BRUSH_TRAVEL=10` 扫描；到不了位会触发 D2=32 |
| 轮刷 | — | `X30/X31` 开位 | `M1` 要求为 1；异常时 `D2=27` |

现场预设：`--preset stall-s3-t99` 复现 2026-10-22 那台“进洗车头后卡住 → T99 原地 40 秒 → D2=25 → S15”的机器（`D32=72`、`X6=0`）。

## 7. 上电常态（`machine.py` 要点）

- `X_IDLE`：所有“到位/正常”类输入为 1；`X44/X45=0`（没按停止/启动）；
- **`X67=0` 不是猜的**：它只被读一次，取 1 会经 `INCP D84 → M501 → M221 清零 → S21 走 S22`，永远进不了 S3；
- `X50` 低电平有效（见上）；
- `M_CONFIG`：`M221/M222/M223/M226/M227/M228=1`（洗车程序选择位），`M224/M225=0`（跳过 S11）；
- `INJECT_M`：`M515=1`（车辆检测到，全工程只读）；`M551/M528/M552=1`（S9 出口支路需要，语义待确认）；
- `DEFAULTS_D`：`D134=1`（上电先屏蔽故障，S20 起改 3）、`D534=1500`、`D30=2`、`D368/D370=1000`。
