# PLC 模拟器文档

> 这里放两类东西：**说明文档**（所有 `.md`）和**机型资料**（梯形图 CSV / `.gxw` / IO 表 / 厂商原始件）。
> 代码目录（`core/` `web/` `simulators/`）里不放文档，只留注释和指向；打开 `docs/<机型>/` 就能拿到
> “说明 + 图纸 + 数据”，不用再跳。

## 目录结构

```
docs/
├─ README.md                     ← 你在这里：文档索引
├─ 接入标准.md                    ← 跨机型：接口契约 / 数据结构 / 看板约定 / 切换方式
├─ 海天/                          ← 一台机器一个目录
│  ├─ README.md                  机型说明（点位 / 命令 / 前置检查 / 工序 / 故障码 / 预设）
│  ├─ 海天洗车机.csv              梯形图指令表（运行时就读这份）
│  ├─ 金达路一号停车场洗车机.gxw   原始工程（G5 闸门对账）
│  ├─ XL200_七代机_IO表.tsv        结构化 IO 表（参考，已知部分有误）
│  ├─ 梯形图语义与现场标定.md      技术底稿（语义口径 / 现场故障反推 / 视频标定）
│  └─ XL200(5刷)输入输出表——七代机_2025.doc   原始 IO 表（现场资料）
└─ _模板/
   └─ 机型说明模板.md              新机型照这个写自己的机型说明
```

| 跑测试 / 验收 | `../README.md` 的“测试”段 + `接入标准.md` §8 |

## 目录约定

1. **一台机器一个目录**，目录名用机型中文名（如 `海天/`），`--plc` 用的英文 key 写在机型说明开头。
2. **通用文档放 `docs/` 根**，不放任何 `simulators/<key>/` 里。
3. 机型目录必须有一份 `README.md`，按 `_模板/机型说明模板.md` 的骨架写。
4. **机型资料（文档 + 梯形图 CSV + `.gxw` + IO 表 + 厂商原始件）都放 `docs/<机型>/`**；
   `simulators/<key>/` 只放代码。打开一个机型目录就能拿到“说明 + 图纸 + 数据”，不用再跳。
5. 新增/改名文档时同步更新本索引与 `../README.md` 的链接。
